# Custom-devboard
My first PCB design project, I used KiCad and the ESP32-S3-WROOM-1 to make this.
It is meant to be a level up from the arduino I have to support me as I begin to create more and more advanced IoT projects.
It features 3 leds, a bunch of capacitors in the right places, a controller module, usbc, and 40 pins. I am not uploading any firmware because I am using the firmware that comes on the WROOM-1 out of box.
I really hope this lets me get better at robotics programming.
